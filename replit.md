# Nova Havens — novahavens.com

Marketing site for Nova Havens Temporary Housing, built with Next.js (App
Router). Start with the root `README.md`; it links to every other document.

- `pnpm dev` — local dev server on http://localhost:3000
- `pnpm build && pnpm start` — production build + server
- `pnpm lint`, `pnpm typecheck`, `pnpm test:smoke` — the checks CI runs
- Docs: `docs/DEPLOYMENT.md`, `docs/SEO.md`, `docs/CMS.md`, `docs/BRAND.md`, `docs/COMPANY.md`
