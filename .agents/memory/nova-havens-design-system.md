name: Nova Havens design-system extraction
description: Durable decisions for the source-backed Nova Havens design-system artifact and its approval-gated migration.
---

The Nova Havens design-system artifact is intentionally separate from the live
Nova Havens app until the user approves migration. Its dark tokens mirror the
source app; its light tokens are an accessible counterpart because the source
presentation is dark-only. The source has no standalone wordmark asset, so the
system uses the text wordmark treatment and must not invent a logo file.

**Why:** The user requested a reusable system and an approval checkpoint before
changing application screens; preserving source fidelity matters more than
forcing a complete migration in the extraction pass.

**How to apply:** Keep the one-gold rule and dark-first preview. Finish the
remaining source-backed families before proposing migration of live screens.
